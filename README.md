# (WIP) Resource-Screening
## Exceptionally simple overview
If you're someone like me who has a lot of resource packs, like a whole stack of them, organizing and customizing your textures might be a pain
<img width="520" height="400" alt="image" src="https://github.com/user-attachments/assets/ff0bf992-46b1-4f4c-8c87-68d75e56f17f" />
<sub>Notice the size of the scroll bar</sub>

  Sometimes, you might want some textures from pack A and some from Pack B, but you don't want Pack B overriding all of Pack A's textures (if that makes sense)
For example,
Let's say Pack A contains a texture for grass and cobblestone. Pack B contains different textures for those two blocks too.
In vanilla Minecraft, it would not be possible to get just the grass texture from Pack A and just the cobblestone texture from Pack B, without manually editing the texture in the resource packs folder. For smaller packs, this is not too much of a hassle, but for large complex packs, escpecially if you have many resource packs like I do, then it can start to get very confusing.

This mod aims to solve that problem, by allowing you more control of the textures you want in the game. This allows you to customise your game to a degree that would have otherwise been harder to acheive.

## 🔻How to download and use 🔻
<details>
<summary>Download</summary>
  
You can download the jar file from the [Modrinth](https://modrinth.com/project/resource-screening) page, which i would reccomend. Alternatively, you could choose to download it from the [releases](https://github.com/shushi93/Resource-Screening/releases) page. Then, put that jar file in the mods folder of your minecraft folder. I recommend searching it up on YouTube for clearer instructions. The mod should work without any further configuration.
</details>

### Get started
To access the texture pack selection screen, you need to go into Options → Resource Packs. There, you can individually select all the textures you want. To get back to the default resource pack screen, you can use the button on the top-left side of the screen.
