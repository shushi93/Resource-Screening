# [Enter_Mod_Name]
### Exceptionally simple overview
If you're someone like me who has a lot of resource packs, like a whole stack of them, organizing and customizing your textures might be a pain

<sub>Notice the size of the scroll bar</sub>

Sometimes, you might want some textures from pack A and some from Pack B, but you don't want Pack B overriding all of Pack A's textures (if that makes sense)
For example,
Let's say Pack A contains a texture for grass and cobblestone. Pack B contains different textures for those two blocks too.
In vanilla Minecraft, it would not be possible to get just the grass texture from Pack A and just the cobblestone texture from Pack B, without manually editing the texture in the resource packs folder. For smaller packs, this is not too much of a hassle, but for large complex packs, escpecially if you have many resource packs like I do, then it can start to get very confusing.

So I present [Enter_Mod_Name]
This mod allows you to pick textures individually for each block, item, gui, etc. No more having to edit resource packs yourself for your own custom look, you can now have greater flexibility in how your game looks!
